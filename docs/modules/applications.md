# Applications

## Obsidian

- **Option:** `obsidian.enable = true;` in `home.nix`
- **Default:** `false`
- **File:** `modules/home-manager/programs/desktop/obsidian.nix`

Obsidian note-taking application. The module wraps the package to unset `NIXOS_OZONE_WL`, forcing Obsidian to run via XWayland rather than native Wayland. This is required because Electron's native Wayland PDF renderer produces a black screen on Hyprland.

Uses `pkgs-unstable.obsidian` rather than stable: Obsidian 1.12+ switched PDF.js to fetching PDFs via XHR from a vault-specific `app://` subdomain, and nixpkgs' 1.12.7 build includes the CORS patch that registers that scheme correctly. The 1.10.3 build in stable lacks the patch and renders PDFs as a blank "0 of 0" viewer.

## VeraCrypt (Disk Encryption)

- **Option:** `veracrypt.enable = true;` in `configuration.nix`
- **File:** `modules/nixos/programs/veracrypt.nix`
- **Default:** `true`

VeraCrypt is a free and open-source disk encryption tool. It allows you to create virtual encrypted disks within files or encrypt entire partitions and storage devices.

### Features

- AES, Serpent, and Twofish encryption algorithms
- Hidden volume support for plausible deniability
- Cross-platform compatibility (Windows, macOS, Linux)
- Hardware acceleration support

### System Configuration

The module configures:

- FUSE support (`programs.fuse.userAllowOther = true`) for mounting volumes
- A setuid security wrapper so the GUI can mount volumes without requiring sudo

### Usage

**GUI:** Run `veracrypt` to open the graphical interface.

**Command line:**

```bash
# Mount a volume
veracrypt /path/to/volume /mnt/point

# Dismount a volume
veracrypt -d /mnt/point

# Dismount all volumes
veracrypt -d
```

## SMB Mount (Network Share Automount)

- **Option:** `smbMounts.<name> = { ... };` in `configuration.nix`
- **File:** `modules/nixos/programs/smb-mount.nix`
- **Default:** `{ }` (no mounts)

Automounts one or more CIFS/SMB shares that are only reachable on a specific network (e.g. a home LAN), without blocking boot or freezing the shell when off that network. Each entry under `smbMounts` is a name (used to derive defaults) plus:

| Sub-option | Default | Description |
|---|---|---|
| `enable` | `true` | Whether to automount this share |
| `server` | *required* | `//host/share` |
| `mountPoint` | `/home/<user>/<name>` | Local mount path |
| `credentialsFile` | `/etc/nixos/secrets/smb-<name>-credentials` | Path to a `mount.cifs` credentials file |
| `uid` / `gid` | `<user>` / `users` | File ownership on the mount |
| `extraOptions` | `[ ]` | Extra `mount.cifs` options, e.g. `[ "vers=3.0" ]` |

```nix
# configuration.nix
smbMounts.kronan-share = {
  server = "//smb.kronan.lan/share";
  mountPoint = "/home/${variables.username}/kronan-mount";
};
```

### Why it doesn't freeze off-network

Uses `noauto` + `x-systemd.automount` so the share is never touched at boot — the mount only happens the moment something accesses `mountPoint`. `x-systemd.device-timeout=5s` / `x-systemd.mount-timeout=5s` bound how long that access can stall if the server isn't reachable (instead of hanging indefinitely), and `x-systemd.idle-timeout=60` unmounts automatically after a minute idle so it doesn't sit connected once you leave the network.

### Credentials

`credentialsFile` is never generated by Nix and must not be committed — the nix store is world-readable. Create it by hand:

```bash
sudo mkdir -p /etc/nixos/secrets
sudo tee /etc/nixos/secrets/smb-kronan-share-credentials > /dev/null <<'EOF'
username=myuser
password=mypassword
domain=WORKGROUP
EOF
sudo chmod 600 /etc/nixos/secrets/smb-kronan-share-credentials
```

## Calendar (GNOME Calendar + QuickShell bar)

- **Option:** `gnome-calendar` + `eds-calendar-events` installed via
  `modules/home-manager/desktop/hyprland/quickshell.nix`

Proton Calendar has no CalDAV support (a deliberate limitation on Proton's part), so the only
officially supported way to sync it elsewhere is a read-only ICS share link. Add it as a web
calendar from within GNOME Calendar itself (**+ → New Calendar → From Web**), pasting the ICS URL
from Proton Calendar's calendar menu → **Share** → **Share via link**. This is a one-time GUI
action — Nix never sees or stores the URL.

GNOME Calendar's backend, `evolution-data-server` (EDS), keeps a local SQLite cache of whatever
it syncs (`~/.cache/evolution/calendar/<source-id>/cache.db`), refreshed automatically every 30
minutes. The bar's clock popup reads events straight out of that cache via `eds-calendar-events`
(a small script built by `quickshell.nix`) — it finds whichever configured EDS source points at
`calendar.proton.me` and queries its cache directly, so there's no second URL or fetch to manage.
Clicking a day with a dot shows that day's events; no synced source means no dots, same as before.

- **Eza** (modern `ls` replacement, aliased to `ls`, `ll`, `la`, `lt`, `tree`)

### Tmux

- **Option:** `tmux.enable` (default: `false`)
- **File:** `modules/home-manager/programs/terminals/tmux.nix`

Persistent terminal multiplexer with a Nord-themed status bar, vi key mode, and seamless nvim split / tmux pane navigation via vim-tmux-navigator.

**Session persistence:** Alacritty auto-attaches to a session named `main` on launch (`tmux new-session -A -s main`). Closing the Alacritty window disconnects the client but leaves the session running. Reopening Alacritty reattaches to the same session — window layout and running processes are preserved.

### SSH Client

Always active (`modules/home-manager/programs/command-line/ssh.nix`). Configures `~/.ssh/config` with sensible defaults for all hosts (`Host *`):

- `AddKeysToAgent yes` — keys are added to the agent on first use
- 60-second keepalives (`ServerAliveInterval 60`, `ServerAliveCountMax 3`)
- Connection compression enabled
- `ControlMaster auto` with a 10-minute persist window (sockets in `~/.ssh/control/`)

A `github.com` matchBlock is preconfigured to use `~/.ssh/github_jckl16` exclusively (`IdentitiesOnly yes`), preventing the SSH agent from offering other keys (e.g. Vagrant keys) to GitHub.

To add host-specific entries, use `programs.ssh.settings` in `home.nix`.
